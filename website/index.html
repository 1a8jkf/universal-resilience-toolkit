Zero-compromise Resilience for Modern JS

Composable retries, rate limits, circuit breakers, and state persistence for Node.js, Bun, Deno, Cloudflare Workers, and Vercel Edge. No mandatory dependencies.

Retries & Backoff

Exponential, constant, or custom backoff. Built-in full and equal jitter to prevent thundering herds on your upstream services.

Rate Limiting

High-precision token bucket or sliding window algorithms to throttle traffic locally or globally with atomicity.

Circuit Breakers

Fails fast when downstream is degraded. Automatically probes health in a half-open state before resuming full traffic.

Pluggable State

Memory, SQLite (via built-in node/bun or better-sqlite3), or distributed Redis clusters via Lua compare-and-swap.

app.ts
import { withResilience } from '@1a8jkf/universal-resilience-toolkit';

const resilientFetch = withResilience(
  async (url: string) => {
    const response = await fetch(url);
    if (response.status >= 500)
      throw new Error(`Upstream HTTP ${response.status}`);
    return response;
  },
  {
    key: 'catalog-api',
    retry: { maxAttempts: 3, backoff: 'exponential' },
    rateLimit: { tokensPerInterval: 10, interval: '1s' },
    circuitBreaker: { failureThreshold: 5, resetTimeout: '30s' },
  },
);

// Will automatically retry, rate limit, and open the circuit if degraded
const response = await resilientFetch('https://example.com');
